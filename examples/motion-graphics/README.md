# motion-graphics

Spring "punch in" motion and monospace text fitted to its box.

<a href="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/motion-graphics.mp4"><img alt="motion-graphics preview" src="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/motion-graphics.jpg" width="640" /></a>

Preview (640x360): https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/motion-graphics.mp4

From the repository root, `just run motion-graphics` opens it in the editor with live reload and
`just render motion-graphics` writes the full video to a file.
