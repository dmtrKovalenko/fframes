# fframes-intro

The 128 second launch video, everything placed on the beat grid of its soundtrack.

<a href="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/fframes-intro.mp4"><img alt="fframes-intro preview" src="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/fframes-intro.jpg" width="640" /></a>

Preview (640x360): https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/fframes-intro.mp4

From the repository root, `just run fframes-intro` opens it in the editor with live reload and
`just render fframes-intro` writes the full video to a file.
