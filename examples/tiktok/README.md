# tiktok

A TikTok-like vertical video.

<a href="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/tiktok.mp4"><img alt="tiktok preview" src="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/tiktok.jpg" width="360" /></a>

Preview (640x360): https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/tiktok.mp4

From the repository root, `just run tiktok` opens it in the editor with live reload and
`just render tiktok` writes the full video to a file.
