# pixel-memory

My dog's memorial video generator (totally randomized).

<a href="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/pixel-memory.mp4"><img alt="pixel-memory preview" src="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/pixel-memory.jpg" width="640" /></a>

Preview (640x360): https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/pixel-memory.mp4

From the repository root, `just run pixel-memory` opens it in the editor with live reload and
`just render pixel-memory` writes the full video to a file.
