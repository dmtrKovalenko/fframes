# audio-announce

An automated workflow to create audio visualisation with automated subtitles.

<a href="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/audio-announce.mp4"><img alt="audio-announce preview" src="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/audio-announce.jpg" width="640" /></a>

Preview (640x360): https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/audio-announce.mp4

From the repository root, `just run audio-announce` opens it in the editor with live reload and
`just render audio-announce` writes the full video to a file.
