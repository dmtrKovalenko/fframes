# made-of-motion

A 20 second promo with pixel objects, a perspective carousel, thermal shaders and per-exposure vector ink, an adaptation of a reference film.

https://github.com/user-attachments/assets/3c51ccae-3541-4c79-817c-f544cf83e415

From the repository root, `just run made-of-motion` opens it in the editor with live reload and
`just render made-of-motion` writes the full video to a file.

## Credits

The film adapts the [reference film](https://x.com/jordanarchivess/status/2107536262894915762) by Jordan Watkins to
fframes. The original cut boundaries and audio are retained.
