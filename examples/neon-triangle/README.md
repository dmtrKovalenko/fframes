# neon-triangle

A minimal shader clip built to make banding and motion artifacts easy to spot.

https://github.com/user-attachments/assets/8f15791f-0dc4-4589-bec4-c63e4ec0f912

From the repository root, `just run neon-triangle` opens it in the editor with live reload and
`just render neon-triangle` writes the full video to a file.
