# neon-triangle

A minimal shader clip built to make banding and motion artifacts easy to spot.

<a href="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/neon-triangle.mp4"><img alt="neon-triangle preview" src="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/neon-triangle.jpg" width="640" /></a>

Preview (640x360): https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/neon-triangle.mp4

From the repository root, `just run neon-triangle` opens it in the editor with live reload and
`just render neon-triangle` writes the full video to a file.
