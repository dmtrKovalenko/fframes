# shaders

GPU shader layers composed with SVG: an SkSL background and a Shadertoy raymarcher clipped into a card.

<a href="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/shaders.mp4"><img alt="shaders preview" src="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/shaders.jpg" width="640" /></a>

Preview (640x360): https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/shaders.mp4

From the repository root, `just run shaders` opens it in the editor with live reload and
`just render shaders` writes the full video to a file.
