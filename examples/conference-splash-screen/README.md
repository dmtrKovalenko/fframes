# conference-splash-screen

One splash screen per conference talk, rendered in batch.

<a href="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/conference-splash-screen.mp4"><img alt="conference-splash-screen preview" src="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/conference-splash-screen.jpg" width="640" /></a>

Preview (640x360): https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/conference-splash-screen.mp4

From the repository root, `just run conference-splash-screen` opens it in the editor with live reload and
`just render conference-splash-screen` writes the full video to a file.
