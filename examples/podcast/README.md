# podcast

An audio visualization for a podcast placeholder video.

<a href="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/podcast.mp4"><img alt="podcast preview" src="https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/podcast.jpg" width="640" /></a>

Preview (640x360): https://github.com/dmtrKovalenko/fframes/raw/main/examples/previews/podcast.mp4

From the repository root, `just run podcast` opens it in the editor with live reload and
`just render podcast` writes the full video to a file.
