fframes – video vibe coding framework that is actually fast

Stop wasting hours waiting for video to be built from the web page in a browser. Vibe code your video on GPU using Rust & SVG framework.

Get started

With your coding agent

Add the official fframes skill from the GitHub repo, then ask your agent for a video.

$ npx skills add dmtrKovalenko/fframes

With cargo

Install the project generator and create a video you can render and preview right away.

$ cargo install --locked cargo-fframes \
    --git https://github.com/dmtrKovalenko/fframes
$ cargo fframes new my-video
